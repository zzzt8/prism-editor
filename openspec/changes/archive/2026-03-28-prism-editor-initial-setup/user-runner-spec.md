# User Runner - 用户运行界面规格

## ADDED Requirements

### Requirement: 用户可以查看可用工作流列表
系统 SHALL 在用户端显示所有已发布的工作流。

#### Scenario: 查看工作流列表
- **WHEN** 用户打开用户端应用
- **THEN** 显示所有可用的已发布工作流卡片

#### Scenario: 工作流卡片信息
- **WHEN** 工作流卡片显示
- **THEN** 包含工作流名称、描述和缩略图预览

### Requirement: 用户可以进入工作流运行页面
系统 SHALL 允许用户选择并进入某个工作流的运行界面。

#### Scenario: 进入运行页面
- **WHEN** 用户点击工作流卡片
- **THEN** 跳转到该工作流的运行页面

### Requirement: 用户可以上传输入图像
系统 SHALL 提供图像上传功能，用户可以上传所需的输入图像。

#### Scenario: 上传输入图像
- **WHEN** 用户在工作流运行页面
- **THEN** 可以上传所需的输入图像

#### Scenario: 输入验证
- **WHEN** 用户上传的图像不符合要求
- **THEN** 系统显示错误提示并要求重新上传

### Requirement: 用户可以调整暴露参数
系统 SHALL 显示开发者开放的参数供用户调整。

#### Scenario: 调整参数
- **WHEN** 开发者开放了某些参数
- **THEN** 用户可以在界面上调整这些参数的值

#### Scenario: 隐藏未开放参数
- **WHEN** 开发者未开放某些参数
- **THEN** 用户看不到也修改不了这些参数

### Requirement: 用户可以执行工作流
系统 SHALL 提供执行按钮，用户点击后运行工作流。

#### Scenario: 执行工作流
- **WHEN** 用户配置好输入和参数后点击"执行"
- **THEN** 系统开始执行工作流并显示进度

#### Scenario: 执行完成
- **WHEN** 工作流执行完成
- **THEN** 显示输出结果和导出选项

### Requirement: 用户可以下载输出结果
系统 SHALL 提供导出下载功能。

#### Scenario: 下载输出
- **WHEN** 执行完成后用户点击"下载"
- **THEN** 浏览器下载输出图像文件

#### Scenario: 下载多尺寸结果
- **WHEN** 工作流输出了多个尺寸
- **THEN** 用户可以分别下载或一键下载全部
