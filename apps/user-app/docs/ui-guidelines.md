# 用户端 UI 规范说明

> **应用**: `apps/user-app`  
> **版本**: 1.0.0  
> **最后更新**: 2026-03-28

本文档说明 Prism Editor 用户端（user-app）的 UI 设计规范和实现细节。

## 设计理念

用户端面向普通用户，强调 **简洁明了**、**低学习成本** 和 **结果导向**。

核心原则：
- 不暴露节点感、连线感、工程工具感
- 用户感觉在"使用功能"，而非"操作工作流"
- 线性流程：Input → Run → Output
- 大按钮、大预览，减少认知负担

### 布局尺寸

| 区域 | 尺寸 | 说明 |
|------|------|------|
| 输入面板 | 360px 固定宽度 | 左侧，包含所有输入和参数 |
| 输出面板 | flex: 1 | 右侧，显示输出预览和下载 |

## 视觉规范

### 颜色系统

用户端使用 Design Token 中的颜色变量，通过 `apps/user-app/src/styles/global.css` 中的别名使用：

| 别名 | Token | 值 | 用途 |
|------|-------|-----|------|
| `--ua-bg` | — | #0D0D0F | 页面背景 |
| `--ua-surface` | — | #14141A | 卡片背景 |
| `--ua-surface-2` | — | #1E1E28 | 输入框/下拉背景 |
| `--ua-surface-3` | — | #2A2A36 | 悬停背景 |
| `--ua-border` | — | #2A2A35 | 边框 |
| `--ua-text` | — | #E2E2EE | 主要文字 |
| `--ua-text-muted` | — | #7A7A8A | 次要文字 |
| `--ua-accent` | — | #6366F1 | 强调色 |
| `--ua-accent-hover` | — | #818CF8 | 强调色悬停 |
| `--ua-success` | — | #22C55E | 成功状态 |
| `--ua-error` | — | #EF4444 | 错误状态 |
| `--ua-warning` | — | #F59E0B | 警告状态 |

### 字体规范

| 用途 | 大小 | 字重 |
|------|------|------|
| 页面标题 (H1) | 26px | 700 |
| 区块标题 | 16px | 600 |
| 卡片标题 | 15px | 600 |
| 正文/标签 | 13px | 400~500 |
| 辅助说明 | 12px | 400 |
| 小标签/徽章 | 11px | 500 |

### 卡片样式

用户端卡片采用更强的卡片感，与开发者端不同：

| 属性 | 值 |
|------|-----|
| 圆角 | 12px |
| 边框 | 1.5px solid `--ua-border` |
| 内边距 | 14~16px |
| 背景 | `--ua-surface` |
| 悬停 | 边框变强调色，背景加淡淡强调色 |

### 禁止事项

- ❌ 显示节点、连线等工程元素
- ❌ 使用技术术语（如"节点"、"端口"、"参数值"）
- ❌ 复杂的导航或设置面板
- ❌ 过多的参数控件（控制在 3-5 个）

## 组件规范

### 工作流卡片 (WorkflowCard)

列表页中显示的工作流入口卡片：
- 包含图标、名称、描述、I/O 计数、入出徽章
- 悬停时边框变强调色，轻微上移
- 点击进入运行页

### 图片上传卡片 (InputSection)

输入面板中的图片上传组件：
- **拖拽上传**：支持拖拽文件到卡片区域
- **点击上传**：点击卡片内的按钮选择文件
- **预览**：上传后显示缩略图预览
- **清空**：显示清空按钮，可重新上传
- **必填标识**：标题旁边显示红色"必填"字样

### 参数控件 (ParamsSection)

参数区使用的控件：
- **Slider**：用于数值参数，带当前值显示
- **Select**：用于选择类参数
- **输入框**：用于文本参数

所有控件样式统一，与卡片风格保持一致。

### 运行按钮 (RunSection)

居中显示的运行按钮：
- **尺寸**：大尺寸（lg），全宽
- **状态**：
  - 就绪：`--ua-success` 绿色背景，"运行"
  - 运行中：`--ua-error` 红色背景，显示加载动画
  - 禁用：半透明，不可点击

### 输出区 (OutputSection)

包含以下元素：

#### 执行进度

- 进度条显示执行进度
- 显示当前节点/总节点数
- 显示百分比

#### 结果摘要

- 成功时：绿色边框，勾选图标，"执行完成"
- 失败时：红色边框，错误图标，"执行失败"

#### 图片预览

- 大图预览（max-height: 400px）
- 点击放大（Lightbox 全屏查看）
- 深色背景衬托

#### 下载面板

- 单图下载：全宽强调色按钮
- 多尺寸下载：ZIP 包下载按钮 + 下拉菜单
- 下载中状态提示
- 下载结果提示（成功/失败）

## 交互规范

### 用户流程

1. **选择工作流**：从列表页选择一个工作流
2. **上传输入**：在输入区上传必要的图片/文件
3. **调整参数**：根据需要调整参数（可选）
4. **运行**：点击运行按钮
5. **查看结果**：查看输出预览
6. **下载**：下载所需格式/尺寸的结果

### 状态管理

| 阶段 | 状态 | UI 表现 |
|------|------|----------|
| 初始 | 空状态 | 上传区域显示虚线边框和上传提示 |
| 输入中 | 拖拽激活 | 上传区域边框变强调色，背景加淡淡强调色 |
| 已上传 | 已填充 | 显示缩略图预览和清空按钮 |
| 可运行 | 就绪 | 运行按钮变绿色 |
| 运行中 | 执行中 | 运行按钮变红色，显示加载动画 |
| 执行完成 | 成功 | 输出区显示预览，下载按钮可用 |
| 执行失败 | 错误 | 显示错误信息，可重试 |

### 动画规范

| 动画 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 页面淡入 | 180ms | ease | 页面切换 |
| 卡片悬停 | 100ms | ease | 边框/背景变化 |
| 按钮悬停 | 120ms | ease | 颜色变化 |
| 模态弹出 | 150ms | cubic-bezier | 弹窗显示 |
| 进度条 | 250ms | ease | 宽度变化 |
| 下载提示 | 150ms | ease | 淡入淡出 |

## 与开发者端差异

| 方面 | 开发者端 | 用户端 |
|------|----------|--------|
| 布局 | 三栏（节点库+画布+属性） | 双栏（输入区+输出区） |
| 风格 | 高信息密度、工具感 | 简洁明了、卡片感 |
| 控件 | 复杂参数表单 | 克制参数控件 |
| 术语 | 技术术语 | 用户友好语言 |
| 结果 | 节点状态 | 图片预览 |
| 下载 | 无 | 有 |
